# getAnimation

`getAnimation` returns the Motion animation that is exposed (`useExposeAnimation`) for a reference,
or `undefined`. Use it outside React's render, for example in an event handler; in a component,
`useExposedAnimation` rerenders when the animation changes.

```tsx
const onClick = useCallback(() => {
  getAnimation(animationReference.current)?.play();
}, []);
```
